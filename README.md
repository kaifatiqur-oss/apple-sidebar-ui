# Apple Design Sidebar UI

A premium collapsible sidebar built with **React + Tailwind CSS**, inspired by Apple's design language.

## Features

- Smooth expand/collapse animation
- Apple-style traffic lights
- Clean active states with system blue accent
- Backdrop blur + subtle borders
- Fully responsive icon-only collapsed mode

## Live Demo

Deployed on Vercel.

## Tech Stack

- React 18
- Tailwind CSS
- Pure CSS transitions (Apple easing)

## How to run locally

Just open `index.html` in any modern browser. No build step required.
